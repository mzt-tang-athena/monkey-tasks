## Spec

Ship 1.3 and put it on the phone, as the first release through
`scripts/release.sh`.

1.3 carries:

- The command pane rises from the bottom edge (#203).
- One wide Add button (#227). A tap adds. A swipe down opens the
  commands, and a swipe sideways changes tab.
- The planner's dates follow a swipe (#197), and it keeps the day you
  picked (#213).
- The tabs run Lists, Planner, Inbox, Journal (#225).
- My order is the default sort (#226).
- Reference notes on a task (#222). It merged before the cut, and the
  operator chose to fold it in on 2026-11-24.
- The new app icon: the operator's monkey, banana yellow in Flexoki
  (#216).
- A drag under a tick lands where you dropped the row (#214).

Deeds (#224) wait for 1.4.

`CHANGELOG.md` lists everything under 1.3.0.

The version becomes 1.3.0, and the Android version code becomes 4.
Land the bump and the dated changelog through a PR first.
