## Spec

Ship 1.0 and start using it on the phone.

1.0 is the app on main once the 1.0 tickets land. It holds the journal
tab, the folded Completed group, the wider day split and the tick burst.
It also holds the Phosphor glyphs, the icon-only bar, the one-screen
week planner and the editor sheet. `CHANGELOG.md` lists every feature.

A release is four things. A tag. A GitHub release. The release APK
attached to it. The app installed on the phone.

GitHub Actions has no minutes left this month, so this machine builds
the APK. The `android` workflow runs `npx expo prebuild --platform
android --no-install`, then `./gradlew assembleRelease`. This machine
runs the same two steps.
