## Spec

The app ships with the Expo starter icon: a blue "A" over guide
circles. It says nothing about this app. The operator picked a new icon
on 2026-11-18. The design is a flat matcha square, `#7A9A3E`, with one
bold white tick.

`docs/adr/20261118-app-icon.md` records the pick and its rejected
concepts.

Every icon asset must come from a committed source. A colour or a
shape change is then one edit and one command. The adaptive icon must
survive the Pixel circle mask, and themed icons must show the tick. The
emulator proves the result.

## Acceptance

- [ ] `app/scripts/app-icon/source/` holds the SVG sources.
- [ ] `npm run app-icon:build` rebuilds every asset.
- [ ] `icon.png` is 1024 square, opaque and full bleed.
- [ ] The adaptive tick fits the 66 of 108 safe circle.
- [ ] `adaptiveIcon.backgroundColor` is `#7A9A3E`.
- [ ] A test fails when a source and `app.json` drift apart.
- [ ] The local gate passes.
- [ ] The emulator shows the icon on the home screen.
- [ ] The emulator shows the icon in the app drawer.
- [ ] Themed icons show the tick, with themed icons on.
- [ ] The ADR records the pick and the rejected concepts.
