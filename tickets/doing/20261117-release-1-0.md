## Spec

Ship 1.0 and start using it on the phone.

1.0 is the app on main once the 1.0 tickets land. It holds the journal
tab, the folded Completed group, the wider day split and the tick burst.
It also holds the Phosphor glyphs, the icon-only bar, the one-screen
week planner and the editor sheet. `CHANGELOG.md` lists every feature.

A release is four things. A tag. A GitHub release. The release APK
attached to it. The app installed on the phone.

GitHub Actions has no minutes left this month, so this machine builds
the APK. The `android` workflow runs `npx expo prebuild --platform
android --no-install`, then `./gradlew assembleRelease`. This machine
runs the same two steps.

## Acceptance

- [ ] `CHANGELOG.md` has the 1.0.0 section. The GitHub release body is
      that section.
- [ ] The full local gate passes on the tagged commit. Record names,
      Vale, `tsc`, eslint, `vitest`, and the whole web suite under the
      shared lock.
- [ ] `v1.0.0` tags the gated commit.
- [ ] This machine builds a release APK from that tag and attaches it
      to the GitHub release.
- [ ] The APK installs on the phone and opens on the sample vault.
- [ ] On the phone, a tick plays its burst.
- [ ] On the phone, Completed opens and deletes its done tasks.
- [ ] On the phone, a journal entry and a food entry land in the note.
- [ ] On the phone, the day split reaches both edges.
- [ ] On the phone, the theme switches and a task sheet opens.
