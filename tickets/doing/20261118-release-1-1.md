## Spec

Ship 1.1 and put it on the phone.

1.1 adds the Inbox Notes tab (ticket 0095, #164). It also fixes the
tick's burst, which painted over the bottom bar (#163).
`CHANGELOG.md` lists both under 1.1.0.

The app version becomes 1.1.0, and the Android version code becomes 2.
A phone with 1.0.0 then takes the APK as an upgrade.

Same release steps as 1.0. GitHub Actions has no minutes this month,
so this machine builds the APK. The build runs alone, in its own
systemd unit.
